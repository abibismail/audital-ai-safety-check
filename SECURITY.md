# Security and responsible use

This repository demonstrates a number-precision corner case using fictional values. It is **not** security software, a certified auditor or a production-ready input validation library.

- Do not submit confidential/customer records as GitHub issues.
- Do not rely on the example for complete AI output integrity or detection of all business errors.
- Preserve large identifiers as strings or use vetted lossless number parsers before values are converted to JavaScript `Number`.
- Report potentially sensitive problems privately to contact@audital.ai; avoid posting credentials or private data.
